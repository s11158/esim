```bash
claude -p "$(cat prompt.txt)" --output-format text < /dev/null > out.txt
```

В промпте перечислить нужные отчёты словами: domain_overview, organic_research, competitors_research, backlinks_research (overview, refdomains, backlinks), keyword_research (phrase_this, phrase_related, phrase_questions, phrase_organic для SERP топ-10), база ae, и попросить вывести сырые результаты как JSON.
