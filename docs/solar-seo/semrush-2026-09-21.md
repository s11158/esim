## Что осталось снять и как

1. Остальные 9 строк Organic Rankings (icoone, статьи про Botox) и SERP топ-10: нужен тариф Pro или юниты для MCP. Проверить статус подписки: https://www.semrush.com/accounts/subscription-info/ (или https://www.semrush.com/mcp-access для юнитов коннектора).
2. Семь оставшихся ключей через Keyword Overview: повторить завтра по одному запросу в сутки-лимите, URL вида https://www.semrush.com/analytics/keywordoverview/?q=hifu%20dubai&db=ae (лимит около 5-6 запросов в день на бесплатном плане).
3. Дочерняя сессия `claude -p`: сначала `claude login` в обычном терминале, иначе "OAuth session expired".
4. Дешёвая альтернатива для позиций: Topvisor (docs/solar-seo/topvisor-2026-09-21.md) и Google Search Console, они не зависят от тарифа Semrush.

## Как снималось (для повторения)

- Organic Rankings: https://www.semrush.com/analytics/organic/positions/?db=ae&q=solar-beauty.ae&searchType=domain - страница грузится 60-120 секунд (скрипты по 15-100 секунд), вкладка дважды падала, текст снимать через get_page_text после полной загрузки, скриншоты не работают.
- Backlinks: https://www.semrush.com/analytics/backlinks/overview/?q=solar-beauty.ae&searchType=domain
- Keyword Overview по одному запросу: https://www.semrush.com/analytics/keywordoverview/?q=<запрос>&db=ae. Bulk-форма через автоматизацию не принимает ввод.
