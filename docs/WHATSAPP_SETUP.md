# Подключение WhatsApp-канала продаж

Две дорожки. Дорожка А запускается за вечер без единой строки кода. Дорожка Б - автоответчик на Cloud API, который сам подбирает тарифы по сообщению клиента.

Важно про модель: мы сравнилка и работаем в ноль. "Покупка" - это переход клиента по нашей партнёрской ссылке на сайт провайдера, платёж принимает провайдер. Поэтому в WhatsApp мы ничего не продаём напрямую, а только подбираем тариф и даём ссылку.

## Дорожка А - без кода, запуск за вечер

Что понадобится: телефон и полчаса времени.

1. Поставь приложение WhatsApp Business (это отдельное приложение, не обычный WhatsApp): Android - https://play.google.com/store/apps/details?id=com.whatsapp.w4b, iPhone - https://apps.apple.com/app/whatsapp-business/id1386412985. Зарегистрируй его на рабочий номер (можно на второй SIM или виртуальный номер).
2. Заполни профиль: открой "Настройки", затем "Инструменты для бизнеса", затем "Профиль компании". Название "eSIM Pizza", категория "Информационные технологии", сайт https://esim.pizza, короткое описание вида "Сравниваем цены на eSIM и даём ссылку на самый дешёвый тариф".
3. Создай каталог: в "Инструменты для бизнеса" нажми "Каталог", затем зелёную кнопку "Добавить товар или услугу". Каждый тариф - отдельный товар:
   - Название: "Канада 75 ГБ / 30 дней - Stellar".
   - Цена: цена провайдера в долларах, например "22.13 USD".
   - Описание: 2-3 строки, что входит, и обязательно фраза "Оформление на сайте провайдера по ссылке" плюс сама партнёрская ссылка (бери её из data/plans.json, поле aff).
   - Фото: флаг страны или карточка с витрины (assets/).
   После сохранения товар появится в каталоге со статусом "На проверке", через несколько минут станет "Одобрено".
4. Ограничение дорожки А: каталог обновляется только руками, автоматической синхронизации с витриной нет. Поэтому держи в нём только 10-15 топовых тарифов из категории 1 - популярные страны с лучшей ценой за ГБ. Раз в неделю сверяй цены с data/plans.json и правь вручную.
5. Сделай ссылку с предзаполненным текстом: формат https://wa.me/НОМЕР?text=ТЕКСТ, где НОМЕР - твой номер в международном формате без плюса и скобок. Пример: https://wa.me/79991234567?text=%D0%A5%D0%BE%D1%87%D1%83%20eSIM (текст "Хочу eSIM" в URL-кодировке). Клиент нажимает ссылку, и у него открывается чат с уже написанным сообщением.
6. Размести ссылку: в шапку профиля Instagram ("Редактировать профиль", поле "Сайт" или кнопка "WhatsApp"), на сайт esim.pizza кнопкой "Спросить в WhatsApp". Длинную ссылку можно укоротить в самом WhatsApp Business: "Инструменты для бизнеса", затем "Короткая ссылка".
7. Проверка: открой ссылку wa.me с другого телефона. Должен открыться чат с твоим бизнес-профилем, предзаполненным текстом и видимым каталогом (кнопка с иконкой магазина в шапке чата).

Результат дорожки А: клиенты пишут в WhatsApp, ты вручную отвечаешь и кидаешь товар из каталога со ссылкой на провайдера.

## Дорожка Б - автоответчик на Cloud API (bot/whatsapp-cloud.mjs)

Бот сам разбирает сообщение вида "Канада 20 гб 14 дней" и отвечает топ-3 тарифами со ссылками. Что понадобится: аккаунт Facebook, Node 20+, около часа.

1. Открой https://developers.facebook.com/apps/ и нажми зелёную кнопку "Create App" (правый верхний угол). Если просит войти - войди через свой аккаунт Facebook.
2. На шаге выбора типа выбери "Business", нажми "Next". Введи имя приложения (например "esim-pizza-bot"), свою почту, нажми "Create App". Появится дашборд приложения со списком продуктов.
3. Найди в списке продуктов карточку "WhatsApp" и нажми на ней "Set up". Если спросит про Business Portfolio - создай новый или выбери существующий. Откроется раздел "WhatsApp" в левом меню.
4. Зайди в "WhatsApp", затем "API Setup". Там уже готовы:
   - тестовый номер отправителя (Test number) и его "Phone number ID" - скопируй этот ID;
   - временный токен (Temporary access token, живёт 24 часа) - скопируй кнопкой "Copy";
   - блок "To" - нажми "Manage phone number list" и добавь свой личный WhatsApp-номер как получателя, подтверди кодом из сообщения.
5. Постоянный токен (чтобы не обновлять каждые сутки): открой https://business.facebook.com/settings/system-users, нажми "Add", создай системного пользователя с ролью "Admin". Затем у него нажми "Add Assets", выбери своё приложение, включи "Manage app". Потом кнопка "Generate New Token": выбери приложение, срок "Never" (или 60 дней), отметь права "whatsapp_business_messaging" и "whatsapp_business_management", нажми "Generate Token" и сразу сохрани строку - второй раз её не покажут.
6. Создай файл .env в корне репозитория (он в .gitignore, в чат и в git не попадает) со строками:

   ```
   WHATSAPP_TOKEN=токен из шага 5 (на первое время можно временный из шага 4)
   WHATSAPP_PHONE_NUMBER_ID=Phone number ID из шага 4
   WHATSAPP_VERIFY_TOKEN=любая своя строка, например esim-pizza-verify-2026
   PORT=3100
   ```

7. Подними туннель, чтобы Meta достучалась до твоего компьютера. Установи cloudflared отсюда: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/ (для Windows - "cloudflared-windows-amd64.exe"). Запусти в отдельном окне терминала:

   ```
   cloudflared tunnel --url http://localhost:3100
   ```

   В выводе появится строка вида "https://случайные-слова.trycloudflare.com" - это публичный адрес твоего бота. Скопируй его. Окно не закрывай: закроешь - туннель умрёт и адрес сменится.
8. Запусти бота в другом окне терминала из корня репозитория:

   ```
   node bot/whatsapp-cloud.mjs
   ```

   Должно появиться "WhatsApp-бот слушает http://localhost:3100/webhook". Если данных ещё нет, сначала выполни "node scripts/export-plans.mjs".
9. Привяжи вебхук: в дашборде приложения открой "WhatsApp", затем "Configuration". В блоке "Webhook" нажми "Edit":
   - "Callback URL": адрес туннеля из шага 7 плюс /webhook, например https://случайные-слова.trycloudflare.com/webhook;
   - "Verify token": ровно та строка, что в .env как WHATSAPP_VERIFY_TOKEN;
   - нажми "Verify and Save". Если написало ошибку - проверь, что бот и туннель запущены и строки совпадают посимвольно.
10. Там же в блоке "Webhook fields" нажми "Manage" и подпишись на поле "messages" (переключатель "Subscribe"). Без этого сообщения до бота не дойдут.
11. Проверка: со своего личного WhatsApp (номер из шага 4) напиши на тестовый номер "Канада 20 гб 14 дней". В течение пары секунд бот должен ответить тремя тарифами со ссылками и строкой "Полное сравнение: https://esim.pizza". Если ответа нет - смотри окно с ботом: там будут ошибки Cloud API с расшифровкой.

Локальная проверка без сети (в любой момент):

```
node --check bot/whatsapp-cloud.mjs
node bot/whatsapp-cloud.mjs --selftest
```

Вторая команда должна напечатать "SELFTEST PASS".

Когда дойдёшь до конца (или упрёшься в любой шаг) - напиши мне "готово" и на каком ты шаге, продолжим настройку вместе: переезд с тестового номера на боевой, витринное имя отправителя и постоянный хостинг вместо туннеля.
